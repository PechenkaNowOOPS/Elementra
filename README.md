# Elementra

**Elementra** — Minecraft-сервер выживания с исследованием, строительством, торговлей, лёгким RP и развитием мира действиями игроков.

**Техническая среда:** Minecraft Java Edition · Purpur/Paper 26.2 · Java 25 · без обязательных клиентских модов.

> **Стадия проекта:** подготовка ядра к закрытому бета-тестированию (ЗБТ). Описанная в спецификациях механика не обязательно реализована. Актуальный доказанный статус см. в [roadmap.md](./roadmap.md).

## Исходники отдельных компонентов

Этот репозиторий — **единый центр проектной документации**, а не монорепозиторий готовых плагинов. Исходники можно разрабатывать и версионировать независимо:

- [ServerMine-ForgeSystem](https://github.com/PechenkaNowOOPS/ServerMine-ForgeSystem) — кузнечная система;
- [servermine-cities](https://github.com/PechenkaNowOOPS/servermine-cities) — города;
- [Elementra-WorldAwakening](https://github.com/PechenkaNowOOPS/Elementra-WorldAwakening) — связанный проект мировой системы.

Наличие репозитория или кода **не подтверждает** компиляцию, интеграцию и запуск на игровом сервере. Для NetherSeals актуальное состояние и блокеры приведены в [roadmap](./roadmap.md).

## Правила работы с документацией

1. При изменении механики сначала прочитать связанные документы и проверить противоречия.
2. Исправлять существующий документ, не создавать новую копию с номером версии в имени.
3. Версию, дату, утверждённость и статус реализации указывать **внутри** файла.
4. Различать: **утверждено**, **реализовано**, **тестируется**, **предложено**, **отложено**, **открытый вопрос**.
5. Не считать систему готовой только на основании ТЗ, наличия исходников или JAR.
6. Перед ЗБТ отдавать приоритет стабильности, сохранениям, отсутствию дюпов, интеграциям и игровым испытаниям — а не увеличению числа механик.
7. Не добавлять в Git мировые сохранения, базы данных игроков, секреты, токены, пароли или приватные конфигурации.
